Run this in Claude Code if you want to check your [installation](/docs/installing/):

```text
/eklavya:setup
```

Setup checks Node.js 22+, the running server and the database. It leaves your
settings alone and does not ask you to choose them. You can start working as
soon as you restart Claude Code after installation.

The database includes starter concepts for `web-auth`, `react`, `node-backend`
and `git`. If something is missing, setup points you to `/plugin` or the terminal
installer so you can fix it.

:::note[In Cowork]
Setup checks the database through the running server. Cowork's shell has a
separate filesystem and cannot check your local database directly.
:::

## Change things later

Use [the dials](/docs/dials/) or the dashboard's [Settings](/docs/dashboard/#settings)
when you want different questions or memory behavior. The
[commit gate](/docs/commit-gate/) is optional and has its own setup.
