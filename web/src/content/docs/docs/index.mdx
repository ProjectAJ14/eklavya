Eklavya is a Claude Code plugin with two jobs: **help you understand the work
Claude produces** and **remember what happened in your project**.

- **Learn as you build.** Short questions connect to the code Claude just wrote.
  Your answers guide the difficulty and schedule future reviews.
- **Carry context forward.** Eklavya saves prompts and work evidence, turns them
  into observations, and recalls relevant history in later sessions.
- **Choose how much it interrupts.** Keep skippable questions, require a passing
  quiz before commits, or use memory alone.

By default, questions arrive one at a time during work, with a four-minute
checkpoint interval and a budget of four questions per session. Memory is on;
commit enforcement is off. [The dials](/docs/dials/) explains how to change this.

## Start here

You need **Claude Code and Node.js 22 or newer** on macOS, Linux or Windows.
Eklavya needs no separate account. Its database and default memory processing
are local; recalled history becomes context for Claude. See
[privacy and data](/docs/memory/) for the boundaries.
