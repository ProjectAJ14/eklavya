All users need **Claude Code and Node.js 22+ with npm** for this install.
It works on macOS, Linux and Windows. [Install Node](/docs/faq/#how-do-i-install-nodejs)
if you need it.

<Steps>

1. **Install Eklavya in a terminal.**

   <span id="a-one-command-from-a-terminal"></span>

   ```bash
   npm install -g eklavya && eklavya install
   ```

   This installs the plugin, local runtime and terminal command. Eklavya starts
   with its defaults and keeps any settings you already saved.
   New installs use `claude-sonnet-5` for memory summaries and prompt feedback
   through your Claude Code login. [What gets sent to Claude](/docs/memory/#how-observations-are-made).

2. **Allow the side panel if you use auto mode.**

   :::caution[Important: side-panel permissions]
   Auto mode can block the quiz panel. Add these three entries to
   `permissions.allow` in `~/.claude/settings.json`. **Keep all existing entries.**

   ```json title="~/.claude/settings.json"
   {
     "permissions": {
       "allow": [
         "mcp__plugin_eklavya_eklavya__panel_sync",
         "mcp__plugin_eklavya_eklavya__panel_answer",
         "mcp__plugin_eklavya_eklavya__present_question"
       ]
     }
   }
   ```

   You can also [ask Claude to add them](/docs/first-session/#if-auto-mode-blocks-the-panel).
   :::

3. **Restart Claude Code and start a task.**

   Ask Claude to build or change something. Eklavya asks short questions about
   the work and remembers it for your next session.

</Steps>

Read [Your first session](/docs/first-session/) for what happens next.
For other hosts, use [Installation options](/docs/installation-options/).
For more install details, see the [FAQ](/docs/faq/#what-does-the-installer-set-up).

<span id="check-that-it-worked"></span>

## Optional: check the installation

```bash
eklavya doctor
```

This checks the runtime, database and plugin. If it reports a problem, follow
[Troubleshooting](/docs/troubleshooting/).
