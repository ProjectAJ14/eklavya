Eklavya is a plugin for [Claude Code](https://claude.com/claude-code). You work exactly as you do now — you ask Claude to build something, and it builds it. The difference is that while it works, Eklavya asks you a **multiple-choice question** about a concept the code it just wrote depends on. One question, not a batch.

You answer with a keystroke. Claude grades it, saves the result to a small database on your machine, and carries on with the task. By default you get at most **four questions in a whole session**, spread through the work rather than piled at the end. Over weeks the questions get harder, the ones you got right stop coming back, and the ones you fumbled return at spaced-out intervals until they stick.

While that happens it also **remembers**. What you asked for, what changed, what failed — recorded as you work and summarised into short observations, so the next session starts knowing what this project has already been through instead of asking you to explain your own repository again. That half is on by default and is governed separately: `quiz.enabled: false` means no questions, not no history. [Memory](/docs/memory/) is the page for it.

That is the whole product: it teaches you the code your agent writes, and it remembers the work.

### What you need

**Node 22 or newer.** Check it with `node --version`. That is the entire list, on macOS, Linux and Windows alike — it runs the server, the `eklavya` command and every hook. If yours is older, [Installing](/docs/installing/) has the upgrade command for your platform.

There is no account, and with the default configuration nothing leaves your machine — the summariser that writes observations and the embedder that makes memory searchable both run locally. Pointing `providers.observer` at a model is the only setting that changes that, and nothing sets it for you.
