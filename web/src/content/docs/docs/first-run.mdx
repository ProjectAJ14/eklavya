Run this in Claude Code after [installing](/docs/installing/):

```text
/eklavya:setup
```

The terminal installer already configures Eklavya. This guided check is useful
if you installed through the marketplace or want help choosing your settings.

<span id="the-five-things-it-does"></span>

## What setup does

<Steps>

1. **Checks the installation.** Confirms Node.js 22+, a running server and your
   database. The starter concept domains are `web-auth`, `react`, `node-backend`
   and `git`. Optional `sqlite3` and `jq` checks support diagnostics and the
   terminal commit gate; missing them does not prevent ordinary use.

2. **Asks how questions should work.** Choose skippable questions (default),
   enforced questions before commits, or no questions. Turning questions off
   leaves memory recording; `memory.enabled` controls that separately.

3. **Asks what to teach.** Choose **concept** for transferable ideas,
   **project** for this codebase, or **learn** for a topic you name. Concept is
   the default. [The dials](/docs/dials/) explains all three.

4. **Adds the git hook if you choose enforcement.** For commits outside Claude
   Code, this hook also needs project-level enforcement and the `jq` and
   `sqlite3` tools. Missing dependencies allow commits through. With a hook
   manager such as husky, setup prints the line to add to that manager. Follow
   [The commit gate](/docs/commit-gate/) to enable and verify it for your project.

</Steps>

Setup writes global settings to `~/.eklavya/config.json`. To make one checkout
different, use `eklavya config set` with `--project` or ask for that explicitly;
settings stay in your home directory. You can change the learning choices
later with [`/eklavya:mode`](/docs/commands/#eklavyamode-value).

:::note[Analytics]
Eklavya sends anonymous daily usage counts, never code, paths, names or text.
Ask Claude to turn off Eklavya analytics, or run `eklavya telemetry off`.
[Usage analytics](/docs/usage-analytics/) lists every field.
:::

:::note[In Cowork]
Setup verifies the database through the running server, because Cowork's shell
has a different filesystem. It skips git-hook installation: Cowork does not
commit, so enforcement can ask questions but cannot hold a commit.
:::

## Start working

Ask Claude to build something. Use `/eklavya:progress` to see your learning
history, `/eklavya:quiz` to request a question, or `/eklavya:memory` to inspect
memory. With enforcement on, `/eklavya:gate` shows outstanding concepts.
