The recommended install sets up the Claude Code plugin, its local runtime, and
the `eklavya` terminal command together.

## Before you start

Use **Claude Code and Node.js 22+** on macOS, Linux or Windows. Check Node with:

```bash
node --version
```

<details>
<summary>Install or upgrade Node.js</summary>

Use the [Node.js installer](https://nodejs.org/en/download), or your existing
package manager:

```bash title="macOS with Homebrew"
brew install node
```

```powershell title="Windows"
winget install OpenJS.NodeJS.LTS
```

```bash title="Linux with nvm already installed"
nvm install 22 && nvm use 22
```

</details>

Git lets Eklavya identify checkouts for project settings and learning progress. The optional terminal
[commit gate](/docs/commit-gate/) also needs a POSIX shell, `jq` and `sqlite3`; ordinary
questions and memory do not.

<span id="a-one-command-from-a-terminal"></span>

## Install in three steps

<Steps>

1. **Run the installer in a terminal.**

   ```bash
   npm install -g eklavya && eklavya install
   ```

   It installs the plugin and runtime, creates the database, and adds two chat
   skills for plain-English controls and saved explanations.

2. **Choose your settings.**

   Use the arrow keys and Enter. Accepting each default gives you skippable
   questions about concepts, spread through your work, and local memory.

   | Setting | Default |
   |---|---|
   | Quiz | On, without commit enforcement |
   | Focus | General concepts behind your code |
   | Cadence | One question at a time during work |
   | Difficulty | Adjusted from your answers |
   | Memory | On |
   | Memory model | Local processing, no extra model calls |

   You can change these later with [the dials](/docs/dials/), or repeat the walk
   with `eklavya install --settings`. Reinstalling normally keeps your settings.

   If Claude Mem is detected, the installer asks which tool should record:
   keep Claude Mem, or import its history and switch to Eklavya. Read
   [Moving from Claude Mem](/docs/migrating/) before choosing if you need the
   migration details.

3. **Restart Claude Code and start a task.**

   A new session loads the plugin. Ask Claude to build or change something;
   questions follow as it logs the concepts involved.

</Steps>

<span id="check-that-it-worked"></span>

## Check the installation

```bash
eklavya doctor
```

This checks the runtime, database driver, plugin registration, settings and
other dependencies. In Claude Code, `/plugin` should also list Eklavya without
errors. A new session shows a short Eklavya banner unless `quiet` is enabled.

If something is missing, see [Troubleshooting](/docs/troubleshooting/).
Otherwise, continue to [Your first session](/docs/first-session/).
[`/eklavya:setup`](/docs/first-run/) is an optional guided check inside Claude.
